FAQ

Is this website JavaScript-free?

Yes. The page contains HTML and CSS only. Product buttons use normal links to page sections.

Can customers buy directly on this version?

This static version does not process payments. It provides the storefront and directs customers to your payment and Discord support process.

Can I put this online?

Yes. Upload the index.html file to a static web host such as GitHub Pages or another HTML hosting service.
